Cấu trúc cuối cùng:

games/lat-hinh-tim-cap/
- index.html
- Build/
- TemplateData/
- các file/thư mục khác Unity tạo ra

Quan trọng: file game chính phải nằm tại:

games/lat-hinh-tim-cap/index.html
