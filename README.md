# Pixel Portfolio — local prototype

Chạy: `python -m http.server 4174 --bind 127.0.0.1 --directory .`

Mở http://127.0.0.1:4174 trong trình duyệt.

A/D hoặc phím mũi tên: di chuyển. Space/W/↑: nhảy (tối đa 2 lần). E: vào cổng Dự án. R: reset. Cảm ứng: dùng các nút trên màn hình.

Các trang là file HTML riêng, đường dẫn tương đối tương thích GitHub Pages. Chỉ chạy local, chưa đăng tải. Dự án mẫu và nội dung giới thiệu cần cá nhân hóa. Background và sprite được tạo bằng AI; game loop và tương tác được viết bằng Canvas 2D. Font tải từ Google Fonts, có font dự phòng.
